# ニュース記事の書き方

1 記事 = このフォルダのファイル。ファイル名がそのまま URL になります。

| ファイル | 内容 | URL |
| :--- | :--- | :--- |
| `<slug>.md` | 日本語（必須） | `/news/<slug>` |
| `<slug>.en.md` | 英語版（任意） | `/en/news/<slug>` |

`<slug>` は半角小文字・数字・ハイフンのみ（例: `service-launch`）。

## 日本語ファイル

```
---
date: 2026-11-20
category: お知らせ
title: 記事のタイトル
summary: 一覧に出す短い要約
---

本文（Markdown）
```

`date` は `YYYY-MM-DD`・`YYYY-MM`・`TODO` のいずれか。`TODO` の記事は本番に出ません（開発サーバーでは「日付未定」として表示）。

## 英語版

同じ見出しから `date` を除いたもの（`category`・`title`・`summary`）と、英語の本文です。

- **日付は日本語ファイルにだけ書きます。** 2 つのページは同じ日付で同時に公開され、食い違うことはありません。英語ファイルに `date` があるとビルドが止まります。
- 英語版を足したら、`src/lib/i18n.ts` の `ENGLISH_ARTICLES` にも slug を足してください（言語切り替えが参照します）。忘れるとビルドが止まり、足すべき slug を表示します。
- 対応する日本語ファイルのない英語ファイルもビルドが止まります。

## 本文の Markdown

使えるのは段落、`###` 見出し（`##` も同じ見出し、`####` は小見出し）、`1.` / `-` のリスト、表、`---`、`**太字**`、`[文字](URL)` だけです（メールアドレスと URL はそのまま書いてもリンクになります）。それ以外（引用、コード、画像、斜体、HTML など）はビルドが止まり、ファイル名と行番号が表示されます。詳しくは `src/lib/markdown.ts`。

記事は `npm run check:claims`（`docs/claims.md`）の検査対象です。本文には `claims-allow` を書けないので、引っかかった文は書いた人に戻してください。

読み込みの仕組みは `src/lib/newsArticles.ts` にあります。
